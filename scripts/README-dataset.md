# Raxim v2 Prompt Image Dataset

This archive contains the full Raxim v2 prompt library as structured data plus a
Python downloader for the generated preview images.

## Contents

- `prompt-manifest.json` — 20,370 prompt items with titles, reusable prompt
  text, aspect ratios, and all Pollinations preview image URLs.
- `download-all-images.py` — downloads every cover and variant image.
- `sample-images/` — a small set of locally cached images (if included).

## Download all images

1. Install Python 3 and `requests`:

   ```bash
   python3 -m pip install requests
   ```

2. Run the downloader:

   ```bash
   python3 download-all-images.py
   ```

   Images are saved to an `images/` folder. The default delay between requests
   is 2 seconds to avoid rate limits; edit `DELAY` in the script if needed.

3. The manifest is a gzip-compressed JSON array. Decompress with:

   ```bash
   gunzip prompt-manifest.json.gz
   ```

## Notes

- Images are generated by Pollinations (Flux model). URLs are public and can be
  loaded directly without authentication.
- The downloader skips existing files, so you can safely stop and restart it.
